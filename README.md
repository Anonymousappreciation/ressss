# 🔐 OFFICE ESCAPE: THE MYSTERY ROOM

An interactive educational escape-room game inspired by mystery workshops with **8 specific clickable room objects**, **Team A and Team B modes**, and **top shelf padlock unlocking**.

---

## 🎮 How the Game Works

1. **Click the Specific Object in the Room Picture**:
   - 🗄️ **Desk Filing Drawers** ➔ Room 1
   - 🌿 **Upper Shelf Green Plant** ➔ Room 2
   - 💡 **Amber Desk Banker Lamp** ➔ Room 3
   - 🏀 **Basketball on Shelf** ➔ Room 4
   - 🛢️ **Oak Storage Barrel** ➔ Room 5
   - 🪜 **Rolling Library Ladder** ➔ Room 6
   - 🪑 **Executive Workspace Chair** ➔ Room 7
   - 🔐 **Security Lockbox Safe** ➔ Room 8

2. **Solve the Object's Challenge Questions**:
   - Answer the multiple-choice workplace questions.

3. **Click "← Back to Room to Unlock Padlock"**:
   - Return to the main mystery room screen.

4. **Click the Padlock on the Top Shelf**:
   - The padlock in the top row flashes with **UNLOCK!**.
   - Click it to physically unlock the padlock, play the metallic latch sound, and receive +20 points!

5. **Click the Golden Master Key**:
   - Once at least 5 padlocks are unlocked, click the big golden key at top right to escape!

---

## 🚀 How to Run Locally

Double-click `index.html` or run:
```bash
python -m http.server 8000
```
Visit `http://localhost:8000`.
